System overview

MedDiag is a Python/FastAPI clinical decision-support backend that analyses ECG, EEG and chest radiographs, explains its reasoning and produces automated diagnostic reports.

API reference

Decision support only. Outputs are not a medical diagnosis and require review by a qualified healthcare professional.
